# Side Stories

> [!abstract] Ελληνικά → [[Παράπλευρες Ιστορίες]]

One-shots, and campaigns played by other groups, set in the same world as **Threads of Fate**. They are not part of the main [[Campaigns]], but they share the same world and can cross paths with the same people, places and events.

Each side story gets a code, **S1, S2, …**, in the order it was played, just as the campaigns are numbered C1, C2.1, … The [[World Chronology]] shows where each one fits in the world's history.
